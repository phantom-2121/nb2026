# nb2026

This file contains nb.py, the code used to analyze the data received from the NanoSight. It includes several statistical tests to evaluate trends in concentration, size (nm), and particle size distribution (PSD). Additionally, zp.py was used to generate Fig. 6 and analyze trends in zeta potential (ZP) and overall distributions across each replicate. Note that the code was generated by Claude. The main libraries, such as Matplotlib, SciPy, Pandas, and NumPy, were used in place of Matlab and replicates the data analysis strategies used in that environment. Links below explain the translation: https://numpy.org/devdocs/user/numpy-for-matlab-users.html, and https://scipy.org/
